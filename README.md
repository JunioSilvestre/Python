# Python — DevOps Engineering Lab

A practical Python engineering repository focused on DevOps, infrastructure automation, Linux administration, cloud engineering, monitoring, observability, and software reliability.

The projects in this repository are designed around real-world engineering scenarios and progressively increase in complexity from Junior to Senior level.

The primary objective is to develop production-oriented Python skills while integrating them with modern DevOps and cloud engineering practices.

## Engineering Levels

Projects focused on building strong Python fundamentals through practical infrastructure and automation scenarios.

## Development Environment

The projects are developed primarily in a Linux environment and are designed to be reproducible and eventually deployable to cloud infrastructure.

Each project may maintain its own:

```text
.venv/
src/
tests/
README.md
pyproject.toml
```

Virtual environments and machine-specific configuration are intentionally excluded from version control.
